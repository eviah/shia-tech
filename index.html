שיבוץ שיעור

זיהוי משתמש

השם ישמש לזיהוי השיבוצים שלך ולמילוי אוטומטי בטפסים. ניתן להחליף בכל עת.

דיווח על תקלת מחשוב

תקנון שימוש בחדר המחשבים ובעגלת הניידים

חדר מחשבים

  • מורה שמגיעה לחדר המחשבים / לוקחת ניידים עם כיתתה, אחראית על תקינות הציוד המתוקשב.
  • לא לשכוח: לכבות מקרן, אורות ומזגנים.
  • אין להכניס לחדר המחשבים אוכל ושתייה.
  • יש להשאיר חדר נקי ומסודר מבחינת כיסאות ולסגור את המזגנים.
  • בסיום השימוש בסוף יום בלבד! יש לבקש מהתלמידים ללחוץ על כפתור התחל ולהכניס את המחשבים למצב כיבוי.

השאלת מחשבים ניידים

  • בסיום השאלת המחשבים באחריות המורה לדאוג כי המחשבים חזרו לעגלת הניידים להטענה.
  • יש לנעול את העגלה בעת לקיחת המחשבים וגם בסיומה.
  • יש להחזיר את המפתח לשלומי השומר בסיום השימוש ולוודא כי המפתח חזר.

חן חכם, רכזת התקשוב

נדרשת הגדרת חיבור לשרת

כדי שכולם יראו את אותו לוח שיבוצים בזמן אמת, האתר צריך להתחבר למסד נתונים חינמי (Firebase). זו פעולה חד-פעמית של כמה דקות:

  1. גשו ל-console.firebase.google.com והתחברו עם חשבון Google.
  2. לחצו Add project, תנו שם (למשל computer-lab-schedule) וסיימו את היצירה (ניתן לכבות Analytics).
  3. בתפריט הצד: Build → Firestore Database → Create database. בחרו אזור קרוב (למשל eur3) והתחילו ב-test mode.
  4. בתפריט הצד: Project settings (סמל הגלגל) → גללו למטה ל-Your apps → לחצו על סמל ה-Web </> → תנו שם ולחצו Register.
  5. העתיקו את אובייקט firebaseConfig שמופיע, ושלחו אותו לי (או הדביקו אותו בקובץ index.html במקום המסומן REPLACE_ME בתחילת ה-script).

עד להשלמת השלב הזה, השיבוצים לא יישמרו באופן גלובלי. אפשר לסגור חלון זה ולהמשיך לצפות בעמוד.
